База знаний + Викторина (SwiftUI)

Это приложение на SwiftUI. Есть список постов с картинками и описанием. Есть викторина с 3 вопросами, 3 вариантами ответа, подсветкой правильного и неправильного. Если ответил верно, добавляется новый пост. В настройках можно включать/выключать заголовок списка, менять высоту строк, всё сохраняется. Тема меняется автоматически по системе. Есть анимации при переходах.

Как запустить:
1. Открыть SwiftUIBase.xcodeproj
2. Запустить на iPhone или симуляторе
3. Переключаться по вкладкам: Знания, Викторина, Настройки
